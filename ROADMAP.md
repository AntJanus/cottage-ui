# Roadmap

> A React component library built with TypeScript and TailwindCSS, distributed as an npm package. Part of the "Build A React UI Library" YouTube series.

## Form Primitives
- **Input** - Text input field with default and error variants. Supports placeholder, disabled, and type props.
- **TextArea** - Multi-line text input with default and error variants. Supports rows, placeholder, and disabled props.
- **Label** - Form label with default and required variants. Associates with inputs via htmlFor.
- **Select** - Dropdown selector wrapping native select with styled chrome. Default and error variants.
- **Checkbox** - Controlled checkbox input. Supports checked and onChange props.

## Layout & Structure
- **Card** - Content container with default, outlined, and elevated variants. Supports header, footer, and children.
- **Stack** - Flex layout helper with horizontal and vertical directions. Supports gap, align, and justify props.
- **Divider** - Visual separator with horizontal and vertical orientations.

## Feedback & Status
- **Badge** - Small inline status indicator with default, primary, success, warning, and danger variants.
- **Alert** - Banner message with info, success, warning, and error variants. Supports title, children, and optional dismiss.
- **Spinner** - Animated loading indicator with small, default, and large sizes.

## Overlay & Navigation
- **Modal** - Dialog overlay with small, default, and large sizes. Portal-based with isOpen and onClose props.
- **Tabs** - Tabbed content switcher with default and pills variants. Controlled with activeTab and onChange.
- **Avatar** - User image or initials display with small, default, and large sizes. Falls back to initials when no image provided.
